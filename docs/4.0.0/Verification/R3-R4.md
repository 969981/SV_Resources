# R3/R4 acceptance gates

1. **TRMDL**: fields match PokeDocs schema and source references are in range.
2. **TRMSH**: each mesh resolves the actual TRMBF reference.
3. **Material/texture**: complete paths and checksums; shader/appearance
   remain UNKNOWN until reviewed.
4. **LOD**: declared model mesh list and exported mesh count compared.
5. **UV**: required TEXCOORD references and typed accessors exist;
   appearance needs human or image-diff review.
6. **Skeleton**: glTF skin/joints/inverse-bind references are valid.
7. **Animation**: if explicitly required, channels point to existing nodes
   and sampler indexes; visual motion remains unverified until reviewed.
8. **Output**: glTF buffers and images exist and satisfy length checks.
9. **Evidence**: reviewer, object name, fingerprint, exact glTF hash,
   and five explicit quality checks must all match to promote.
10. **ID provenance**: never bind game IDs to models by filename alone.

Test fixtures: original p0_bag0000_00_bag00 TRMDL/TRMSH, synthetic glTF,
and end-to-end incremental scheduler tests. CI runs Windows .NET 10 exporter
against a real model separately. A schema-only PASS is not a full model PASS.

## Third-party sources / redistribution review

The locally vendored tools/gftool/LICENSE is GNU GPL version 2, and the
separate tools/SV.R3.ModelExport project compiles one original gftool source
file directly. Distribution of the combined binary must honor the applicable
GPL obligations, including providing appropriate license notices and source.
The pinned ScanMountGoat/ultimate_tex decoder carries an MIT license
(see its LICENSE in that repository); copying its code/binaries should
retain the required copyright and permission notice.

Neither open-source tool license gives permission to redistribute original
Nintendo/Game Freak game resource bytes. GitHub Actions upload only bounded
JSON metadata manifests and exclude converted textures/models/animations.
Do not auto-publish raw or reconstructed game assets without a separate
rights/authorization review.
