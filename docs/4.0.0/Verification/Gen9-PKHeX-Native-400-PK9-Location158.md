固定遭遇的 202 对可匹配模板中，**191 对**仅额外引入了地点 ID \`158\`，其他 11 对为不同地点差异；还存在 1 对无法按非地点字段配对的模板（参考侧物种 23 / Lv15，原生侧物种 297 / Lv40），不可忽略。

野生原生独有 3,655 条中，有 2,835 条属于全新的地点、跨区、物种、形态、性别、时间、天气签名，另有 820 条使用与参考版相同的签名但等级范围不同（非逐行配对）。

**16 份两版均合法但匹配类型改变不应划入“完全一致”**。固定地点的 14 份，在参考中分别被解释为 \`EncounterSlot9\`（11）和 \`EncounterOutbreak9\`（3），嵌入原生表后均识别为 \`EncounterFixed9\`；另有 2 份野生等级样本由 \`EncounterOutbreak9\` 转为 \`EncounterSlot9\`。即使 \`Valid=true\`，遭遇来源及潜在 RNG 判定仍需独立验证。

## 地点 158 的集中异常

| 真实 CSV 记录（非游戏实捕） | 原生独有 | 参考独有 |
|---|---:|---:|
| 野生 \`cross_from_id=158\` | 2,337 | 161 |
| 野生 \`location_id=158\` | 603 | 130 |
| 野生 \`location_id=156 && cross_from_id=158\` | 236 | 26 |

\`2337/3655=63.9%\`，说明原生独有野生记录多数跨区来源都指向 158；但这些数据**不证明** 158 的关联错误，也不证明其正确。

原生 pkNX 源码：\`tools/pkNX/pkNX.WinForms/Dumping/Gen9/Encounter/EncounterDumperSV.cs\` 定义 \`tolX=tolY=tolZ=30f\`，\`IsContainedBy\` 与 \`IsCloseEnoughDistance\` 均传递该容差；\`IsCrossoverAllowed\` 仅排除 ID 8、124。 
\`EncounterSlotDumper9.cs\` 在跨区点激活和 \`Nearby\` 汇集时调用碰撞检测；\`FixedSymbolDumper9.cs\` 在扩散地点时调用 \`TryGetBleedArea\`。这些是**可检验的几何扩散嫌疑**，暂未证实属于错误。
