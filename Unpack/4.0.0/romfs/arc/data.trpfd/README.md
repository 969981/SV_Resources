# SV 4.0.0 native data.trpfd descriptor index

Original input: 4.0.0/1/arc/data.trpfd (20,266,112 bytes), kept unmodified.

The _index directory contains real GFTool.Core parsed native outputs (not copies of the source file):
- descriptor_summary.json — verified original SHA-256, file counts and pack counts
- pack_index.tsv — native pack index, filename, size and referenced files
- file_index.tsv.gz — per-file hash, package number and any hash-cache-matched virtual path

Generated by GitHub Actions workflow sv-m1-descriptor.yml. The index describes data.trpfs but does not claim that data.trpfs was restored or that any virtual files were extracted. Those must be validated independently.

See docs/unpack-roadmap.md for provenance/acceptance rules.

## Verified result

Actual native TRPFD parse, SHA-256 check, and Git commit succeeded on 2026-11-05. Source has 408,641 referenced files, 23,589 pack descriptions, 407,647 known paths, and 994 unknown.
