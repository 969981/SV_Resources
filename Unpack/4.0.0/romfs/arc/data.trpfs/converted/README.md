# converted/ — standard formats with verification

Mirror original virtual relative paths. Put validated conversion outputs here:
PNG, UTF-8 CSV/JSON, glTF/GLB, etc., only after a format-aware converter
successfully produces that output. Never turn renamed binary bytes into .png
or .json to imply conversion.

R1 AHTB labels can be exported to CSV (text remains NOT_DECODED).
BNTX → PNG is blocked until a tested decoder is configured; BRTI metadata
is stored in parsed/ separately.
